# aplicativo-figma
🍽️ Prato Perto

📌 Sobre o projeto

O Prato Perto é uma solução digital desenvolvida para facilitar a busca por opções de alimentação próximas ao usuário. A proposta é conectar pessoas a restaurantes e estabelecimentos de alimentação de forma simples, rápida e intuitiva.

O projeto foi pensado a partir da necessidade de tornar mais fácil encontrar lugares para comer, considerando fatores como localização, praticidade e facilidade de acesso às informações.

---

❗ Problema

Encontrar um lugar para comer pode ser uma tarefa demorada, principalmente quando o usuário não conhece bem a região ou precisa tomar uma decisão rapidamente.

Entre as principais dificuldades identificadas estão:

- Dificuldade para encontrar restaurantes próximos;
- Muitas opções disponíveis, dificultando a escolha;
- Falta de informações organizadas;
- Necessidade de acessar diferentes aplicativos ou sites;
- Dificuldade para descobrir novos estabelecimentos na região.

Esses problemas podem tornar uma tarefa simples, como escolher onde comer, mais demorada e pouco prática.

---

💡 Solução proposta

O Prato Perto propõe uma plataforma que reúne informações sobre estabelecimentos de alimentação próximos ao usuário em uma experiência simples e intuitiva.

A solução permite que o usuário:

- 📍 Encontre restaurantes próximos;
- 🔎 Pesquise estabelecimentos;
- 🍴 Visualize diferentes opções de alimentação;
- ⭐ Consulte informações relevantes sobre os estabelecimentos;
- 🗺️ Tenha uma experiência orientada pela localização;
- 📱 Navegue por uma interface simples e fácil de utilizar.

O objetivo é reduzir o tempo necessário para encontrar uma opção de alimentação, oferecendo ao usuário informações organizadas para auxiliar sua escolha.
